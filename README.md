# SubMonitor

使っていない iPhone 12 を、机に置く常時点灯のサブモニターにする Web アプリ。
操作は一切せず、置いておくだけで表示が更新され続けます。

## 表示するもの

| 場所 | 内容 | 状態 |
| --- | --- | --- |
| 左上 | 日付（月・日・曜日） | P1 実装済み |
| 中央上 | 時計 | P1 実装済み |
| 右列 | 天気（朝・昼・夕・夜）。現在の時間帯だけ明るく表示 | P1 実装済み |
| 右下 | 明日の天気（最高・最低・降水確率） | P1 実装済み |
| 左下 | Spotify で再生中の曲（長い曲名はゆっくり流れる） | P2 で接続予定（今は仮表示） |
| 中央下 | Google カレンダーの今日・明日の予定 | P3 で接続予定（今は仮表示） |

- 天気：Open-Meteo（石川県野々市市）、30分ごとに更新
- 時間帯の区切り：朝 5〜10時 / 昼 10〜15時 / 夕 15〜19時 / 夜 19〜5時
  - 現在の時間帯は「今」の予報、それ以外はその時間帯の代表時刻（7時 / 12時 / 17時 / 21時）の予報
- URL の末尾に `?demo` を付けると、曲と予定にサンプルを表示します（見た目の確認用）

## iPhone での使い方

1. Safari でページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動し、横向きに置く
4. 設定 → 画面表示と明るさ → 自動ロック →「なし」

## ファイル

- `index.html` 画面の構成
- `style.css` レイアウト・配色・フォント（844×390 の座標で設計）
- `app.js` 時計・天気・表示の更新
- `fonts/` PC で確認するときの代替フォント（Inter, SIL Open Font License）。iPhone では標準の SF Pro を使用
