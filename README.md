# SubMonitor

使っていない iPhone 12 を、机に置く常時点灯のサブモニターにする Web アプリ。

## 表示するもの（予定）

- 日付・曜日・時刻
- 天気（石川県野々市市、Open-Meteo）
- Spotify の再生中の曲（PC・スマホどちらで再生中でも）
- Google カレンダーの今日・明日の予定
- タイマー

## 現在の段階

P0：動作確認用の最小ページ（全画面表示と画面スリープ防止の確認）

## iPhone での使い方

1. Safari でこのページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動する
4. 設定 → 画面表示と明るさ → 自動ロック →「なし」
